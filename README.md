# Armoury: Eisenhorn

**Project status:** Planning

Armoury: Eisenhorn is a planned armoury mod for *Warhammer 40,000: Rogue Trader*, inspired by Eisenhorn.

This repository currently contains only the project foundation. The scope and equipment selection have not yet been defined, and no mod functionality has been implemented.

## Project structure

- `src/` — future mod source and game-data definitions
- `assets/` — future models, textures, audio, and other authored assets
- `docs/` — design notes and technical documentation

## Development

Technical requirements, build instructions, and contribution guidance will be documented once the implementation approach has been established.
